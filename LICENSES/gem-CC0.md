This project converts the original STL to a centered Y-up GLB, regenerates flat normals, and applies its own runtime materials. Original geometry remains 22 triangles. The source file, hashes and conversion script are retained. This is a simplified visual model, not a standardized brilliant-cut or manufacturing CAD.
