# 戒指实验室

React + Three.js + React Three Fiber + drei 的本地珠宝配置演示。无专有珠宝 SDK，无后台、价格计算和支付。

## 启动

使用 Node.js 22+，在本目录执行：

```sh
npm ci
npm run dev -- --port 5179
```

打开 http://127.0.0.1:5179/ 。验证：`npm test`、`npm run build`、`npm run inspect:gem`。

## 当前样板（2026-10-29）

成品戒指现在有三款可切换款式：铺钻单钻、复古椭圆、以及带替换主石的经典光环。前两款来自本地 `webgi-jewelry` 演示的 Draco 成品模型（该仓库为 CC BY-NC-ND 4.0，模型仅可作本地研究，公开部署前需替换），保留了原始雕蜡、爪镶与密钉细节；经典光环仍是 Diamond Shader Lab 的 MIT 配钻戒托。另有 19 款独立宝石，以及保留的参数化结构 DIY。宝石库按选择加载一款 GLB，19 款合计约 160 KiB，成品模型约 0.95–1.1 MiB。加载缓存保留原模型，展示时克隆几何；切换时释放本实例的几何、材质与光学纹理。

2026-10-29 的渲染对照同时调整了金属反射棚、抛光粗糙度、宝石明暗与观察者遮挡，并修复地面颜色未随预设生效的问题。实际对照、剩余差距与同款商品验收要求见 [商业展示对照记录](docs/commercial-render-review.md)；这不代表与 Blue Nile 达到视觉或实物一致性。

当前链路：配置 → 成品款式 / 单件宝石 / DIY → 原创双环境摄影棚 → 金属局部遮蔽 + BVH 宝石光学 → 纸白 sweep + 接触阴影 → 静止 32 样本累积 → 克制 Bloom → Neutral / sRGB。两套光线预设统一管理环境旋转、亮度、曝光、金属粗糙度和金属补光。

- 成品模型在落入场景前统一做轴向对齐、等比缩放和落地，款式差异集中在 `src/assets/finishedRings.ts`。
- 金属改用真实棚拍 HDR（Poly Haven `studio_small_09`，CC0）作为 IBL；场景内另加五盏大面积光（顶部、正面、侧后、底部反弹），补出白 sweep 和柔光箱应有的长条高光。宝石仍用高对比光卡环境，保持切面火彩。
- 展台背景现在有两档：默认的**纯白 Listing** 使用透明画布 + 纯白页面底 + 接触阴影，商品图导出压白底，适合商品主图；**暖调展台** 使用跟随相机的棚拍 sweep（顶部纸白、底部暖灰、中心很轻的灯池），适合品牌页。两种模式都与产品共用同一条 tone mapping。页面外壳为暖象牙底上的白瓷面板，预览区与配置区以发丝线分隔。
- 金属增加掠射角边缘高光、加强顶点烘焙遮蔽，后处理加一次很轻的对比/饱和度 grade。
- 接触阴影按款式重新捕获，不再沿用上一款模型的阴影；阴影平面在边缘做 alpha 渐隐。
- Bloom 保持 0.004 / 0.007（阈值 3.2），曝光 0.87；没有 SSR/SSAO，金属的屏幕空间反射和缝隙遮蔽仍是下一步。

- 金属局部遮蔽在载入时以静态戒托 BVH 烘焙到顶点，只调制金属的间接光。
- 标准 / 高质量均独立追踪 RGB，预算分别为 5 / 7 次内部相交；每次出射用 Fresnel 分配透射与反射能量。超出预算的能量丢弃，不当成已经穿出宝石。出射和表面反射可命中实际金属戒托，再近似采样其环境反射。
- 四个固定视角可生成并下载当前画布分辨率的 JPEG；每个角度等待静止累积后再截取。生成时锁定相机操作，结束、取消和超时恢复控制。商品图片模式重用本次结果；没有结果时显示明确标注的白金色固定样板图。
- 三维模块延迟加载；浏览器不支持 WebGL 时提供固定图片。图片为实时渲染预览，不是离线路径追踪照片。
- 19 个 3DM 都没有声明物理单位。GLB 保留源数值与切面法线、仅将轴转为 Y-up。单件展示统一平面最大宽度，同时保留长宽高比例；成品只适配圆形主石。

建模交付、转换与限制见 [资产接入说明](docs/atelier-assets.md)。当前模型来源见 [第三方说明](THIRD_PARTY_NOTICES.md)。两款 WebGI 成品模型仅作本地效果研究，不可商用或再分发，公开部署前必须替换。旧六爪研究模型和 EXR 仍保留在仓库，默认展示不加载它们。

### 当前边界

宝石出射后的金属着色采用有界近似；没有宝石互相折射、全场景路径追踪、真实焦散或全光谱计算。局部遮蔽是静态顶点采样；非圆形装配、生产尺寸、克拉与价格仍需业务和建模规范。移动端只做桌面浏览器窄屏检查，实际手机 GPU 与长时间显存表现尚未验证。构建仍有大包体积提示。

## 先前六爪版本记录（已被当前默认样板替换）

配置 reducer → 六爪参考 GLB / 参数化 DIY → 独立金属与宝石 EXR → 开源 BVH 宝石光学 + 地面平面反射 + 接触阴影 → 静止时 32 样本累积 → 克制 Bloom → 单次 ACES / sRGB 输出。

- 默认展示用户提供的六爪参考实模（约 5.06 万三角面），保持原装配，仅替换金属外观；不把 CAD 缩放当成可制造的尺寸编辑。参数化 DIY 保留素圈/分叉、三种金属、三档主石比例，两种模式不丢失原有 DIY 选择。
- 标准/高质量分别使用 5/7 次折射追踪预算；像素比上限为 1.75/2。高质量分别追踪 RGB，标准使用更省算力的快速色散。
- 当前使用用户 GLB 中引用的两张真实 EXR，全部本地加载，Draco 解码器也本地提供。参考模型/EXR 仅作效果研究，未确认商业使用授权；没有包含 iJewel SDK 或其专有 shader。旧原创摄影棚和 Poly Haven HDR 保留归档，不在当前链路使用。
- 本地光学材质基于 MIT drei 顶点/BVH技术，折射出射方向采样宝石环境，表面 Fresnel 采样真实环境反射，而不是混向白色；支持按传播长度衰减，当前无色主石的吸收系数为零。每次绘制同步实际相机及帧缓冲尺寸，包含地面镜像相机和累积抖动相机。
- 六瓣开放镶座、圆润爪尖、封闭金属扫掠端口与更柔和的戒臂倒角。结构仍是展示用程序几何，并非布尔融合的生产 CAD。
- 阴影只在换结构、尺寸或画质时重新捕获，标准/高质量分别使用 512/1024 分辨率与一轮/两轮模糊。离屏目标和材质均由本地模块管理并释放，避免上游柔影组件反复重挂载的资源问题。
- 平面倒影分别使用 512/1024 分辨率，带轻微过滤与距离衰减。相机限制在地面上方。静止后通过 Three TAARenderPass 累积 32 个抖动样本，收敛后停止请求帧；相机/材质/模型/结构/窗口变化会重新累积。这不是运动重投影 TAA。
- 辉光阈值 2、标准/高质量强度 0.015/0.025。简化材质模式关闭倒影和后处理，降为普通玻璃材质、256 分辨率接触阴影。
- 整体、主石近景、镶座侧面快捷视角；手动旋转/缩放、自动旋转、重置。
- 选择仅保存至当前浏览器；不是云端设计单。
- 主石由 22 三角面的旧样模升级为 MIT 明亮式切工模型，252 三角面。三角面数量不等于宝石学切面数量。

## 先前六爪版本的模型接口（历史）

参考模式已接入真实 GLB；DIY 模式仍为程序化几何，不是制造 CAD。生产资产应约定毫米单位、统一原点/轴向、戒臂与镶座分组、精细倒角、独立金属/宝石材质槽、闭合宝石表面与切面硬法线。当前适配器按已检查的 `Brillant_1` 节点识别主石，并保留祖先变换；不能直接视为任意 GLB 自动识别器。

运行 `node scripts/pack-brilliant.mjs` 可从已归档的外部 glTF 重建当前 GLB 与哈希清单。旧 `prepare-gem.mjs` 只用于原型 CC0 石头，不应用它覆盖当前主石。

## 先前六爪版本的边界（历史）

不是 iJewel / Helzberg 的等效商用渲染器：没有离线路径追踪、真实焦散、镜头效果或全光谱色散。折射出射主要采样环境，不追踪镶爪等场景对象；未加入屏幕空间 SSR/SSAO、运动重投影 TAA，也没有复制复杂编织戒臂。参考模型/EXR 的商业授权仍未确认，不应直接发布成商用素材。高质量模式增加 GPU 成本，窄屏检查不等于移动真机性能测试。构建仍可能有主包体积警告。

素材来源、许可证见 THIRD_PARTY_NOTICES.md；实施与验证记录见 IMPLEMENTATION-LEDGER.md / TEST-REPORT.md。
