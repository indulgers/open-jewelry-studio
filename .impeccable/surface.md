# Ring configuration surface

Mode: Operate. Audience and purpose: see PRODUCT.md. Scope: one local web demo.

## Direction contract

THESIS: The ring is the content; configuration stays legible and secondary. No pretend shopping cart or pricing.

OWN-WORLD: Warm limestone field, ivory controls, charcoal text, restrained brass selection. Clear sans-serif Chinese UI; precise, spacious controls rather than dashboard cards.

STORY: Inspect the ring, change construction and finish, rotate it, save the selected configuration locally.

FIRST VIEWPORT: Large left Viewer fills roughly two thirds of desktop width, right column holds labeled controls; quiet header and compact toolbar, no marketing hero. On mobile Viewer precedes controls.

FORM: User-approved functional configuration layout, code-led; no concept-seed key because the design was pinned before execution and launcher is unavailable.

SIGNATURE: Metal switching changes the ring in the same continuous scene; view angle stays fixed so differences remain apparent. Motion is the real object/camera, not decorative entrances.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
