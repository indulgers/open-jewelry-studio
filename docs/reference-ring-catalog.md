`assets/source/<id>/source.obj` 是按连通部件标注金属、主石、外围配钻和戒臂配钻的源模型，保留原文件所有三角面。`source.json` 记录输入文件 SHA-256、部件包围盒及数量。新模型共有的 174 面宝石部件经过原款视图核对，花冠款确实只有主石及两颗配钻，未自动补满空镶位。

在仓库根目录重新生成某款资源：

```sh
node scripts/pack-ring-02.mjs assets/source/ring-floral/source.obj public/models/atelier/ring-floral/ring-v1.glb
```

若改变已发布模型，递增文件版本并同步 `catalog.ts`，以免命中长期缓存。Meshopt 压缩与旧款一致，不删减面；宝石保留切面法线，金属在载入时按 45° 折角生成平滑法线。新款文件约 601 KB–1.1 MB，使用解码 worker 和按路由预加载，不在首页预载全部模型。材质、HDR 白光棚和折射着色器与现有编辑器共用。

四个新款保留原款切形、尺寸和镶座布局，支持已有镶嵌区域的宝石外观、刻字文本、撤销、恢复原款、对比、独立本机草稿及截图加购。刻字是方案和位置示意，未写入模型几何。源文件未声明物理单位，场景仅等比归一化，圈号与生产尺寸待校准。旧围钻款继续提供戒头、石径和自动排钻等原有参数操作。

首页以用户 HTML 为视觉依据，顶部 select 提供四种主题，编辑器和购物车使用相同变量。四张新款近景佩戴图与原款模型图均链接到对应编辑器；选购原款创建独立购物车条目，不覆盖已有定制草稿。佩戴图标为 AI 示意，来源及最终提示词见 `campaign-provenance.md`。

验证：157 个单元测试通过，原有 FORME 圈孔和 256 组边界组合检查通过。隔离 Chrome 在 1440、393、320 像素宽度检查四主题首页、原款购买、旧款编辑及购物车；逐款验证四个新模型渲染、宝石变化、刻字确认、对比禁用加购、草稿互相隔离与重载、320px JPEG 配置图片、价格与购物车数量。未进行实物打样或支付验证。

## 部件组合与选款

原款继续作为定制起点。正式编辑器将 5 款戒头和 3 类戒圈做成图文选项，铺钻紧跟所选戒圈。分段式和纤细可选素面或单列铺钻，宽肩为双列铺钻。5 个戒圈版本与 5 款戒头形成 25 种搭配，沿用来源模型的主石、镶座和铺钻。围钻原款的参数编辑和部件组合各自保存草稿。

换款期间 3D 留在上一套已加载搭配，待部件就绪后在同一画布更新。镜头延续当前角度和缩放，观察视角按钮可重新取景。确认方案和购物车图使用已完成加载的当前搭配。

款式增多后的「查看全部」沿用已验证的 B 原型。在当前选款区内展开带图目录，可按名称或造型搜索、按外观分类。点卡即试搭，保留筛选和列表位置，返回后显示当前所选。手机端将 3D 保留在列表上方，列表独立滚动。铺钻继续随戒圈结构显示。
