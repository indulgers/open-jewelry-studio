# 从模型上传到组合编辑器

适用范围：整戒 OBJ、可区分的戒头和戒圈，以及沿左右戒臂排列的单列或双列配钻。文件与发布版本保存在 R2 私有桶；C 端按当前发布版本加载部件，不需要再登记模型文件名或修改前端款式数组。

## 建模师和运营如何操作

1. **上传复核 → 上传 OBJ**。选择整戒模型，等系统生成三维预览和连通网格列表。原文件保留，系统识别结果先进入复核。
2. **检查分区**。使用已有的自动识别、相似部件选择和批量分配，确认主石、戒头装饰钻、戒臂配钻、戒头金属、戒圈金属以及可替换的配钻镶爪。戒头下方或侧面的装饰钻应归戒头，不能按高度直接当成肩钻。连成同一网格的戒头与戒圈，需建模师先拆开。
3. **检查接合点并生成部件版本**。使用推荐接合点，结合侧面预览和接合标线检查，必要时调整。预览不等于工艺确认；尺寸与制作要求仍由工艺人员复核。
4. **部件管理 → 命名**。填写整套及戒头、戒圈名称；展开“编辑器分类与铺钻”，设置戒头结构、戒圈结构名称、戒臂样式。支持重新铺钻的戒圈启用“允许自动排钻”。配钻镶爪必须独立复核，不能将承重戒臂误分为可替换镶爪。
5. **用于商品**。可以创建新商品，也可以选择“更新：已有商品”。替换旧模型时更新原商品，保留商品编号、名称、价格和首页位置。
6. **商品管理 → 保存草稿并预览**。填写名称、介绍、基础价、排序；首页精选保持 4–5 款。封面可上传，也可由标准角度的 3D 截图生成，不要求额外制作模特图。
7. **检查三维与试排钻**。旋转看侧面接合、戒头装饰钻和戒臂。铺钻戒圈可试改石径与长度，检查颗数、间距和镶爪。试排后点“恢复原款排钻”，再确认发布，避免商品封面与默认配置不一致。
8. **确认发布**。发布后，完整目录和组合编辑器读取新版本。新戒头、新戒圈会自动进入“查看全部”；默认卡片只展示少量选项和当前选中项。旧发布版本在新版本确认前保持不变。
9. **C 端验收**。进入商品定制，分别与旧戒头、旧戒圈混搭；对支持铺钻的戒圈试改两项参数；加入购物车，核对数量、参考价和方案截图。未上架商品不会作为新选择出现。

仅修改部件名称、分类或排钻开关后，商品页也会提示保存新草稿。部件资料在预览后又被修改时，发布会被阻止，要求重新保存并预览。

## 本次自动化补齐的工作

- 编辑器从发布目录读取戒头、戒圈、配钻文件、分类和价格；模型按需读取，切回已加载组合复用缓存。
- 未知模型的排钻轨迹从已复核肩钻位置推导；镶爪来自复核用途，而不是模型编号或固定网格名称。
- 混搭以接合点为起点，检查真实网格，移动完整戒头避开配钻并保持金属接触；允许的小间隙生成连接件，无法安全接合则提示复核。
- 改石径或长度后重算颗数、间距和镶爪，并再次检查连接；新戒圈的配钻按真实戒臂表面落位，避免沿用旧镶架高度。
- 换款保留当前画面和画布；组合草稿按商品编号保存，兼容旧款草稿入口。购物车保存当时的名称、价格、部件配置和三维截图。
- 加购时服务端核对两个部件的发布版本与报价。后台已发布新版本时，旧页面需刷新后重新确认。

## 验收与复测

本轮构建通过。包含实际已发布部件的回归共 53 个测试文件、194 项测试通过；11 套部件逐一混搭并检查九组排钻参数，共 1,089 个状态。检查金属接合、跨部件钻石干涉、重排钻石与戒臂/其他钻石干涉，以及新镶爪与戒头钻石干涉。正常镶爪与其所固定钻石的设计接触不作为穿模错误。

下载公开发布版本的验收输入，再运行几何检查：

```sh
node scripts/cache-published-parts.mjs https://open-jewelry-studio.vercel.app /tmp/xiangyan-parts
JEWELRY_PART_FIXTURES=/tmp/xiangyan-parts npx vitest run scripts/verify-published-combinations.test.ts
```

结果写入输入目录的 `audit.json`。测试只读取公开发布文件，不修改线上商品。

当前自动排钻提供石径 80% / 90% / 100%、长度 70% / 85% / 100%。不规则绕线、多方向分叉、无法分离镶爪的模型需人工复核，必要时关闭自动排钻并保留原款。画面与网格验收不代替珠宝制作的强度、尺寸和加工验证。
