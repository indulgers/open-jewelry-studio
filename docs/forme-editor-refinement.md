# FORME 模组工作室：交互与形变约束

本轮调整针对 Web 模组 DIY。实际模型始终可见，工具按款式、花形、尺寸、材质、素材分组；手机使用底部工具区，滚动限于当前工具面板。桌面保留右侧工具栏。保存明确写入当前浏览器，修改可撤销、重做，单个参数和花形组都可恢复。

## 当前四照花的编辑范围

| 参数 | 范围 | 处理方式 |
| --- | --- | --- |
| 花瓣开合 | −10% ～ +10% | 视觉控制量；接缝处位移、斜率归零 |
| 花瓣扭转 | −4° ～ +4° | 与开合使用连续的局部变形，接缝保持原位 |
| 浮雕厚度 | 90% ～ 120% | 放在折叠的进一步调整中 |
| 表面弧度 | 5% ～ 25% | 与厚度一起约束 |
| 花纹宽度 | 5 ～ 7 mm | 与重复数量联动 |
| 戒指内径 | 16 ～ 23 mm | 同步调整戒圈基准，保留 0.25 mm 径向余量后切孔 |
| 重复数量 | 根据尺寸计算，上限 18 | 控制模组宽高比；交替或镜像排列采用偶数 |
| 项链长度 | 38 ～ 48 cm | 排列示意，不含扣件，不是完整项链实测长度 |

滑杆、步进、重置、JSON 导入、分享链接和本机存档恢复使用同一套约束。旧设计在内存中归入当前范围，原存档只有再次明确保存才会覆盖。自定义 STL 未标定形变范围，关闭花瓣形变、厚度和弧度调整，保留排列、尺寸和材质。

戒指模型完成切孔后再替换画布内容；切孔增加独立部分、剩余体积低于 55%、源网格不封闭或结果为空时，拒绝本次修改并保留前一模型。原四照花 STL 自带三个独立部分，检查比较修改前后的数量，不把原始部件视为新增破碎。这不是完整自相交检查、实体融合或制造认证。

## 材质与取景

使用确定性的棚拍柔光反射、金属边缘反射和抛光/柔缎两档表面，修正圆柱切孔后的法线，保留应当锐利的边界。旋转不会切换材质或启用随机采样。银、金、玫瑰金和石墨都是外观示意，不对应实际合金成色。窄画布按短边保持取景范围，正交与透视共用此逻辑。

## 验证与范围

78 项单元/交互检查、切孔脚本、256 组边界检查与生产构建通过。构建仍报告既有的大包提示。

- 自动检查覆盖真实嵌入 STL 的 256 组边界组合：戒指/项链、普通/镜像交替、开合、扭转、厚度、弧度、宽度和尺寸端点。检查投影翻面、法线有效性、切孔结果；该批戒指组合最少保留 88.2% 体积，没有新增独立部分。
- 原有 STL 导出净空检查继续通过，包括镜像、圆柱不接触模型、完全切空和不封闭源模型。
- 本机存档恢复、参数上限、一次撤销和坏 STL 导入保留作品已在浏览器操作验证。
- 在 1440×900、768×1024、390×844 三个视口检查画布与界面，整页宽高均未溢出。手机是浏览器尺寸检查，未在 OPPO / iPhone 真机复测。
- 本轮未修改或部署实体融合后端，未同步至小程序。
- 浏览器导出菜单和 JSON 导出事件正常触发、控制台无错误，但内置浏览器自动化未返回下载完成事件，文件落盘未确认。STL 序列化与几何净空由自动检查验证。

这套范围只约束当前素材的视觉编辑，不承诺所有连续参数组合均已穷举，也不意味着设计可以直接铸造。原模型的连接和局部壁厚仍需独立验证。
