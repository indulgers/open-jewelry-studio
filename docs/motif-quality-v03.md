# 相言 Motif Lab V0.3 · 真实材质、戒臂与金属融合预检

> 此文件记录实现方法与验收边界。Vintage Alhambra 仅作为内部结构参考，不是品牌授权复刻或官方生产 CAD。

## V0.2 -> V0.3 改动

| 项目 | V0.2 问题 | V0.3 实现 |
|---|---|---|
| 母贝 | 纯白塑料感、简单线条 | 保留上传 OBJ 形状，生成 UV；新增可重复生成的 nacre albedo/roughness/bump 多图层；低强度干涉与清漆 |
| 金属 | 过曝、大片 HDR 黑白镜面 | 降低镜面强度、改进金属统一参数；环形戒臂更柔和的高光，金珠独立加粗并降低密集程度 |
| 小钻 | 靠预置颜色模拟的稀疏面片 | 独立封闭多面钻石几何，支持透明度、色散和 IOR 上限 2.333，独立镶座与四枚小爪 |
| 戒臂 | 平面圆环挤出 | 戒臂沿圆周扫掠真实截面、内缘圆角、上肩逐渐加厚，指孔穿戴方向仍为 X 轴 |
| 金属连接 | 多个网格彼此相交但未焊接 | 复用本地 Manifold WASM，通过显式按钮布尔并集，检查封闭边、实体连通数与指孔轴线 |
| 项链 | 链节太粗 | 细椭圆链节，交错旋转，连接耳独立成环；仅显示项链可见局部 |

## 何谓“通过”

- React/TypeScript 构建成功；纹理生成在 WebGL 浏览器可运行。
- **轮廓验证**：旧的 7 个上传 OBJ 仍能切换，不因 UV 改造修改源文件。
- **物理空间验证**：戒臂多档内径 16/18/21 mm 的网格射线检测通过，最小清孔空间在几何层不被填充。
- **拓扑验证**：钻石为闭合三角曲面，金属戒臂为闭合三角曲面；真实 Manifold 执行布尔并集并要求单个连通实体。
- **视觉验证**：自动在 Chrome WebGL 中拍摄项链正面、戒指 45°、指孔、金属隔离、蝴蝶项链、融合结果和材质细节；需人工检查商品质感与参考图差距。

## 测试方式

```sh
npm ci
npm test
npm run build:public
# 本地已有 Chromium 时:
npm install --no-save --ignore-scripts playwright-core@1.58.0
node scripts/motif-visual-capture.mjs
```

相关文件：
- `src/motif/nacreMaterials.ts`：母贝纹理生成，纯程序化，无第三方产品照片的版权问题。
- `src/motif/metalMaterials.ts`：金属展示参数；仍非测量的 18K 合金 BRDF。
- `src/motif/brilliantGeometry.ts`：小钻封闭三角网格及边拓扑检查。
- `src/motif/comfortFitGeometry.ts`：带圆角和肩部渐变的闭合戒臂。
- `src/motif/motifMetalFusion.ts`：显式布尔融合预检，可返回带诊断的单一金属网格。
- `src/motif/qualityUpgrade.test.ts`、`src/motif/motifMetalFusion.test.ts`：几何、材质与三档戒围的断言。

## 严格边界与待办

1. **不提供生产级 STL**：金属 Manifold 布尔通过仅代表部分实体网格封闭和连接。尚无最薄支撑处的完整厚度扫描、铸造偏移补偿、金属疲劳、皮肤舒适度或材料检验。
2. 母贝与金属保持独立；未实现真实倒角承托、材料涨缩和镶嵌锁固力。中心小钻虽有独立爪位，其防脱尺寸未被珠宝工匠确认。
3. 钻石透明/色散是实时光学近似，不包含多次全路径追踪、镶座内部多次反射或精准色散光谱。
4. 细链为可观察结构，不含闭环运动学与全长 42 cm 链节动力学；长度仅在参数记录中注明参考值。
5. 实物参考图存在可见的材质纹理与工艺细节，当前程序纹理和 PBR 不能声称摄影级一致；需继续逐视角 screenshot review。
6. 上传 OBJ 的对外商用授权和四叶草整体设计相似性风险需在公开发布前复核。

所有导出标记 `VISUAL_PROTOTYPE_ONLY`，直到制造和工艺验收完成。
