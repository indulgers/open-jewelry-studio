# 相言 Jewelry Platform · Figma 与 Codex 协作

- Figma 设计文件：[Jewelry Platform — Design System](https://www.figma.com/design/vhveeXfbk2ISOddFXsORxf)
- 源项目：[indulgers/open-jewelry-studio](https://github.com/indulgers/open-jewelry-studio)，盘点基线 `8f4103b`
- 验证分支为 `design/figma-workflow`，等待审核。
- 本轮以相言现行前台和后台为范围。四照花、FORME 与其嵌入入口属于已移除的旧版。
- 后台同仓，Vite 有 `index.html` 和 `admin/index.html` 两个入口。管理页三个导航视图共享 `/admin/`，使用页面状态区分。

## 设计同事怎么交付改动

1. 在 Figma 里找到对应页面和状态。复制基线帧，命名为「页面 · 修改意图」，保留该帧的移动和桌面视图链接。对某个组件的改动可直接分享组件或实例的节点链接。
2. 修改文字、布局和组件属性。在修改说明里写清楚哪些页面共用改动，哪些状态需要一起调整。3D 画面只是当前配置的静态参考。
3. 把节点链接、需要修改的状态和验收要求交给 Codex。例如「将围钻组合编辑器的观察视角工具栏按此节点更新，保留原有相机和选款逻辑，验收 1440 和 390 两个宽度」。
4. 审核对比图，点击实际页面里的相关操作。设计和功能审核通过后再合并分支。

## Codex 从设计读回代码

1. 获取文件和节点 ID，创建同一任务的 Figma MCP 会话。用 `get_design_context` 读取具体节点，通过 `get_variable_defs` 核对变量，通过 `get_screenshot` 保存设计参考。映射表用于定位已有组件和样式。
2. 从最新基线开分支。复用现有组件与状态，只调整该节点对应的 UI。浏览器里的产品图片、3D、价格、筛选和错误状态继续由项目运行时提供。
3. Figma 导出的 SVG 先进行检查。本轮只允许 svg、g、path 和经验证的绘图属性，拒绝脚本、事件属性、嵌入 HTML、外链和其他主动内容。通过后以本地静态资产引用。
4. 运行 `npm test` 和 `npm run build`。保存相同视口的原版、Figma 和代码版截图。打开真实页面验收对应交互，再交审核。

## 把新页面或状态回写到 Figma

1. 在无生产密钥的隔离检出启动本地应用，将 `XIANGYAN_MODEL_DIR` 指向独立目录。使用仓库公开原款、虚构商品资料及演示购物车。后台禁止使用生产账户、订单和客户信息。
2. 在桌面与移动宽度走到目标页面，等数据、图片和 3D 完成加载。对于立即失败的页面或接口，用隔离测试数据复现错误状态。
3. 用远程 `generate_figma_design` 申请独立捕获 ID，使用官方捕获脚本提交该状态。对于哈希路由，在浏览器进入状态后调用脚本，避免捕获参数覆盖路由。脚本只运行于隔离浏览器。
4. 读取工具的确认结果并记录节点 ID。用 `use_figma` 整理命名、层级；比对图片、文本和 SVG，使用可复用组件逐段替换。每次更新同一文件，保留需要审核的旧帧。
5. 更新页面映射。已成功提交的捕获 ID 只有一次有效，重复提交出现 409 时，查询原捕获状态。

## Starter 文件限制

Figma 将 7 个分组放进 3 个页面。设计系统含 Foundations / Components，产品页含 Storefront / Jewelry Editor / Admin Console，QA 含 Responsive / Interaction States。Starter 的每个变量集合支持一个模式，法式、意式和建筑黑白存为独立集合。组件默认绑定巴黎极简的变量。系统字体若 Figma 账号未安装，人工整理的中文文字使用 Noto Sans SC / Noto Serif SC。

## 第一轮往返结果

- Figma 对照帧 [围钻原版](https://www.figma.com/design/vhveeXfbk2ISOddFXsORxf?node-id=9-2)、[工具栏提案](https://www.figma.com/design/vhveeXfbk2ISOddFXsORxf?node-id=15-2)、[Auto Layout 工具栏实例](https://www.figma.com/design/vhveeXfbk2ISOddFXsORxf?node-id=15-206)。
- 现有工具栏改为四个等宽操作位，背景绑定主题色。戒面俯视和镶座侧面 SVG 已从 Figma 读回，并通过结构检查。桌面与手机测试分别测得 54 px 和 56 px 高，图标为 16 × 16 px，两种宽度均未产生横向滚动。
- 原版、Figma 和 React 版截图均为 1440 × 1004。另有原版与实现的 390 × 844 截图，以及加购证据。见本轮交付的「编辑器往返对比」HTML。
- 实际操作通过桌面 3D 拖动旋转、桌面和移动端切换「镶座侧面」、主石改蓝宝石、铺钻直径和长度调整、加购后截图读取。示例排钻结果为 8 颗，同列间距为石径的 38–40%。
- 展台四角度 JPG 是独立功能。本地开发模式的导出测试停在「生成已取消」，独立静态构建的复测未进入可导出状态。该功能的验收仍待完成。现行组合编辑器通过购物车提供配置截图。
- `npm test` 通过 193 项、跳过 1 项依赖外部发布夹具的用例，内孔与包络检查通过。`npm run build` 成功，构建保留既有体积提示。
- [Git 分支](https://github.com/indulgers/open-jewelry-studio/tree/design/figma-workflow)，提交 `2f4f471`。改动限于视角工具栏的 JSX、CSS 与两个 SVG，待设计审核后合并。
