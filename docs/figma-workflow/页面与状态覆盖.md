## 尚待完成

- 部件库批量和版本移除的后续状态、登录超时、上传失败、3D 加载失败与重试。后台登录、版本记录、发布和上下架确认已用隔离的本地测试接口捕获。
- 移动端以 390 × 844 验证共享布局。逐款手机稿、其他主题的逐页截图、各 CSS 临界宽度和键盘焦点状态尚待补齐。
- Figma Starter 当前已用完 MCP 编辑调用额度。两个主按钮、后台输入框和编辑器视角工具栏已建组件，只有往返样例的工具栏验证了组件实例。现有捕获帧仍可编辑，部分帧尚待归入对应分组及改用组件实例。
- 展台四角度 JPG 导出未通过本地往返验收。开发模式测试显示「生成已取消」，静态构建复测未进入可导出状态。编辑器加购截图已在桌面及移动端验证。
- 版本历史和上下架示意使用虚构记录；初次捕获的历史与上下架确认状态缺少本地测试封面。发布确认已使用修正后的封面测试数据。
