# 相言 · 佩戴级结构研究 V0.2（非制造 CAD）

此案例参考 Vintage Alhambra 四叶草的镶嵌与边缘工艺逻辑，用于内部构造研究，不是品牌官方 CAD 或授权复刻。

## V0.1 的错误与本次修正

上一版 `ProductAdapter` 使用两条 `TubeGeometry` 曲线代替项链链节，又把戒臂和主题放在近乎同一平面，所以 3D 虽然能拖动，但从几何和佩戴逻辑看都不对。

- **项链**：去掉两根直杆。左右为沿空间曲线分布的椭圆闭合链节，每隔一节旋转 90°，以两只独立圆环连接到实际导入的 OBJ 轮廓两侧。画面显示的是链条局部，JSON 保留参考链长 42cm。
- **戒指**：戒臂为含真正孔洞的闭合环形实体，世界 X 为手指通过方向。将四叶草托座绕 X 轴旋转 -90°，放到戒臂外缘、朝世界 +Y；两侧增加真实曲面肩部连接。戒围独立于四叶草尺寸，不随放大主题而改变。
- **材质**：降低珠光母贝与金属底托之间的悬空距离，重新排双层金珠边框，添加内凹部位的金属点；母贝采用低强度珠光干涉和细微纹理，不再是均匀白色塑料。
- **验证**：新增“指孔”观察视角和 7 档名义内径计算校验，界面直接显示保守几何下限。

## 模型坐标约定

| 组件 | 主要坐标与约束 |
|---|---|
| 原始主题 | XY 面，外观正面朝 +Z，默认 15mm，OBJ 原始单位不明 |
| 项链装配 | 外轮廓上肩左右各有连接环，细链在 XY 附近由独立小环延伸 |
| 戒指主体 | YZ 面连续环形，X 轴为穿戴方向 |
| 戒指主题 | 旋转 -90° 到 XZ 面，中心位于戒臂径向外侧，正面朝 +Y |
| 戒臂参数 | 名义内径 16–21mm，径向厚度参考 1.5mm，宽度 2.25mm，倒角 .12mm |
| 主题嵌片 | 位于独立金属底托之上，边缘形成双排金珠 |

## 浏览器中如何验收

1. 打开 `/#/motif-case` → 项链 → 正面，放大左右连接件，要求看到一个个椭圆链节与圆环，不能是光滑杆件。
2. 切到戒指 → 45°，要求装饰件位于戒臂外缘；切换“指孔”，从手指进入方向看到完整贯通的空孔。
3. 把名义内径分别切到 16mm、18mm、21mm，指孔应扩大，但主题的尺寸不改变。
4. 通过“爆炸视图”分别查看底托、嵌片、金珠包边和装配结构；对应部件应保持独立材质与层次。
5. 对照产品参考照片，分别截取正面、佩戴角度、侧面、连接部位的浏览器图片，视觉评审需单独完成。

## 不能误称为已实现

即使这一版拥有贯通几何环和独立链节，**仍未完成适合上手佩戴的工程认证**：尚无实体碰撞扫描、戒臂与底托布尔融合、制造公差、宝石或贝母实际固定力、人体工学及材料强度验证。导出的 GLB 只用于设计评审，不可直接作为工厂 STL/CAD。链节尚无布料/铰链动力学。

商用前需确认上传 OBJ 素材权利，并基于相言自己的原创外观完善产品形态。
