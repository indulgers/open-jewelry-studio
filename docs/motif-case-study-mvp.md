# 相言 · 四叶草结构拆解工作台（MVP）

此目录是为 `indulgers/open-jewelry-studio` 准备的增量补丁，而不是替代现有网站。参考 Vintage Alhambra 的构造逻辑做结构研究，**不包含品牌 Logo、商标或官方生产 CAD 文件**。

## 安装方式

1. 将 `src/motif/` 合入现有仓库 `src/motif/`。
2. 将 `public/motif-lab/assets/` 合入现有仓库同名目录（包含用户提供的七个 `.obj`）。
3. 将 `src/App.tsx` 增加 `motif` hash route，推荐 `#/motif-case`。
4. `npm ci && npm test && npm run build && npm run dev`，用 `#/motif-case` 打开。

## 已实现

- 七个原始 OBJ 独立加载，并从网格投影提取了七套轮廓 JSON。
- 四层结构：金属底托、单独嵌片、双排珠粒包边、可替换适配器。
- 产品：戒指和项链切换；边框/金属/嵌片材质切换；参数化尺寸调整。
- 三维预览：正交相机、旋转、缩放、三视角、零件隔离、Z 轴爆炸视图。
- 导出：GLB 可视化模型、JSON 配方、PNG 视角截图。

## 几何及制造边界

- 原始 OBJ **没有标注单位**。主轮廓统一按最大 XY 方向 15 mm 做研究性缩放，不代表真实成品尺寸。
- 7 个模型在上传状态均经过 `trimesh` 检查为 watertight；**这并不代表装配后是连续可铸造实体**。
- 片材锁固、镶爪、内部支撑、真实链节、制造公差、金属最小壁厚、布尔融合、物理尺寸范围、金属牌号及价格计算尚未验证。
- 目前的金珠包边与链条是**程序化展示几何**，不是品牌真实分件和铸造级 CAD。
- GLB/PNG/JSON 用于设计评审；不可直接送厂。若需 STL/OBJ 制造文件，应接入现有 `/api/forme/*` 几何服务，经检查后再导出。
- 公开商用之前需核对用户上传 OBJ 的资产授权与独立设计的知识产权边界。

## 测试

`motifProfiles.test.ts` 验证全部 7 个轮廓的面积、有效坐标、尺寸归一化和来源唯一性。完整视觉回归和 GPU/WebGL 性能仍需在项目原始环境中运行。
