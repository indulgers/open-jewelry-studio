# 商业展示对照记录 · 2026-10-29

本轮针对“戒臂像塑料、宝石内部不够接近 Blue Nile”的反馈，检查了实际页面、现有模型和材质，再调整同一个模型的灯光。结论是金属反射有所改善，但还不能把当前样板当成实际商品的可信呈现。

## 对照依据

- [Blue Nile 对照款](https://www.bluenile.com/engagement-rings/design-your-own-ring/diamond-whisper-side-stone-engagement-ring-in-14k-white-gold-by-james-allen-item-315462) 实际包含可拖动的 Three.js 戒指视图，并配合静态商品与佩戴图片。不能把它概括为“纯摄影、几乎没有交互”。静态图的制作来源没有核实，不能凭图片判断全部实拍。
- 本地样板的整体修改前后使用相同模型、白金色、柔光商品棚和同一整体相机；实际 CSS 视口为 984×692。两张截图保存在工作区 `../research/2026-10-29-commercial-render/`。
- Blue Nile 与样板的戒托款式、主石比例和画面大小不同。此次对照只能支持反射、结构可读性和显示方式的判断，不能作为同一 SKU 的精度或优劣测试。
- “我们的火彩、交互压倒性更好”没有对照实验支持。互动能力存在，不等于画面更真实，也不等于用户更信任。

## 已修改

| 观察到的问题 | 对应改动 | 当前范围 |
| --- | --- | --- |
| 戒臂大面积暗灰，高光宽且发糊 | 提高棚内基础反射，增加窄黑卡和渐变柔光；粗糙度从 0.16 / 0.115 降到 0.065 / 0.055 | 改善抛光金属的反射条带，没有改变几何或模拟真实镀层 |
| 主石亮白碎片偏多，内部层次难辨 | 收窄并降低宝石环境亮区；降低环境强度与色散 | 保留真实切面追踪，没有绘制假的八心八箭、裂纹或净度特征 |
| 观察方向缺少相机/观察者遮挡 | 出射光线接近观察方向时加入平滑的遮光锥 | 约 10–17° 的美术近似，尚非实测摄影装置；镜面视图使用其自身相机 |
| 地面预设颜色未生效 | 修正 Reflector 构造参数覆盖传入颜色的问题，并降低倒影强度 | 新回归测试先复现失败，修复后通过 |

钻石暗区可以来自观察者遮住环境光，不必把它解释成杂质；参见 [GIA 对 obscuration 的说明](https://www.gia.edu/gia-news-research/transformation-diamond-cut-quality-grading)。当前遮光锥只是这一现象的近似，不能代表切工评级。

## 仍有明显差距

**模型。** 当前戒托是开源展示资产，爪头偏圆、主镶座与戒臂连接细节不足，不能代表公司的生产款。主石来自用户文件，但原 3DM 没有物理单位。继续调整曝光不能补出正确倒角、爪根、镶口和实际比例。

**光学。** 本轮细节图中主石中央仍有较多灰色区域。现有计算是有限次数的 RGB 光线追踪，出射命中金属后使用近似反射；金属外观和宝石使用各自的环境图，未形成一致的全场景光传输。没有宝石之间的折射、完整光谱、实测灯具或真实焦散。增加追踪次数能改善部分路径截断，不能自动修正模型和灯光。

**实物对应。** 当前能说明选择如何改变样板外观，不能说明某颗库存钻石的颜色、净度、切工和瑕疵。商品材质、尺寸、证书和库存石身份必须来自真实商品数据。生成的四视角 JPEG 仍是同一个实时渲染器的输出，不能当实拍证据。

## 下一件应当交付的素材

选择公司计划销售的一枚真实戒指，先把这一枚验收通过。建模同事交付毫米单位的原 CAD、分件 Web GLB、同款装配尺寸和一致视角的参照图；明确戒臂厚宽、倒角、爪位、主石长宽高、腰围与镶口位置。金属保留正确圆滑法线，宝石保留切面硬边；清理重复面、穿插与悬浮部件。

用同款、同视角、相近灯光检查外轮廓、结构连接、金属反射及宝石内部。由建模/商品同事确认生产对应关系，再定为标准资产。按这个标准扩展款式，避免每换一个 GLB 就临时调一套 shader 掩盖素材问题。完整文件约定见 [素材接入说明](atelier-assets.md)。

离线渲染可以作为稳定的商品主图，实时 3D 服务旋转和配置；实际钻石详情和佩戴比例需要对应实物的资料。这三类图应保留来源标识，不混淆预览与实物。
