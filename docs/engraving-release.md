# 刻字体验接入

组合编辑器（SourceRingStudio）新增中文输入、宋体／简洁黑体／英文斜体的视觉预览、三种对齐、示例文字及真实戒圈内侧表面的文字预览。输入后仍需确认，才会保存到原有草稿及购物车。取消、撤销、原款对比保留原有语义。未改价格或业务 API。

`ReferenceDesign.engravingStyle` 是可选字段，旧草稿缺省为宋体／居中。新增字段经过白名单解析，购物车摘要同时记录文字、字形与对齐。所有字体均为系统字体效果示意，未承诺生产字体版本、字高或可制作性；贴附层不会修改生产几何。

四照花组合原型在独立目录和仓库，未包含在此次正式部署中。

注意：当前 feature/prd-acceptance-a 分支的游客服务器保存与人工复核功能未合入 main，本次基于线上 main 独立接入。后续合并该分支时，consumer.ts 的服务器设计白名单也须保留并校验 engravingStyle，摘要需带上字形和对齐；不要只保留 engraving 字符串。
