## 轮次

1. **原始**：Atelier 光环、平灰底、无落影、主石偏灰。
2. **第一轮**：接入 WebGI 成品模型、浅色底、构图拉近、主石替换。
3. **第二轮**：Studio HDR 金属环境、五盏面光源、白底同曝光。
4. **第三轮**：暖调展台，相机跟随 sweep、灯池与接触阴影。
5. **第四轮**：纯白 Listing（默认），透明画布 + `#fff` 白底，商品图导出压白底。

注：01–02 为早期截图，相机与 UI 略有不同；03–05 为同一相机、同一尺寸。03 用玫瑰金展示金属色修正，01/02/04/05 为默认黄金。
